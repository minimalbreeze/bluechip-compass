# 🧭 블루칩 나침반

**50년 뒤에도 있을 회사부터 시작하는 초보자용 주식 가이드.**
국내(KOSPI)와 미장(NYSE·NASDAQ)을 상단 토글 하나로 오가며 같은 화면을 비교합니다.

👉 https://minimalbreeze.github.io/bluechip-compass/ (접근 코드 필요)

**만든 사람과 지인만 쓰는 앱입니다.** 검색에 노출되지 않고, 첫 화면에서 접근
코드를 묻습니다. 설치·가입 없음. 빌드 도구 없음. 계정도 서버도 분석 스크립트도
없고, 입력한 값은 전부 사용자의 브라우저에만 남습니다.

> ⚠️ **이 앱은 투자 교육 자료입니다.** 특정 종목의 매수·매도를 권유하지 않고
> 어떤 수익도 보장하지 않습니다. 종목 점수는 공개된 사업 구조를 바탕으로 한
> 정성 평가이며 가격·실적 데이터가 아닙니다.

## 무엇을 하는 앱인가

대부분의 주식 정보는 **"지금 뭐가 오를까"** 에 답한다. 이 앱은 그 질문을 아예
다루지 않는다. 대신 두 가지만 한다.

1. **"50년 뒤에도 이 회사가 있을까"** 를 6개 축으로 채점한다.
2. **"그래서 오늘 나는 얼마씩 어디에 넣나"** 를 계산해준다.

그래서 화제성 있는 종목이 아니라 폐기물 처리 회사나 산업용 가스 회사가 상위에
오고, 많이 오른 종목은 "안 망하지만 안 흔들리진 않는다"는 경고와 함께 위성으로
분류된다.

**첫 화면이 결론이다.** 홈은 "지금 시장이 어떤가"와 "내 돈이 지금 어떤가"에만
답한다. 공부는 맨 뒤에 있다 — 초보자는 공부하다 지쳐 아무것도 못 사거나,
건너뛰고 아무거나 사거나 둘 중 하나가 되기 때문이다.

## 내 주식 — 팔까 / 둘까 / 더 살까

증권사 앱에 **이미 보이는** 매수금액과 수익률만 옮겨 적으면 된다. 이 앱은
시세를 조회하지 않는다.

판정은 우선순위대로 하나만 붙는다.

| | 언제 | 뜻 |
|---|---|---|
| 🔴 다시 생각 | 이 앱이 평가하지 않은 종목 | 왜 샀는지 세 문장으로 적을 수 있나 |
| 🟠 근거 점검 | 50년 점수 62 미만 | 코어가 아니라 위성으로 다룰 자리 |
| 🟠 한 종목 집중 | 비중 25% 초과 | 한 회사에 계획 전체가 걸려 있다 |
| 🟡 목표 밖 | 목표 구성에 없음 | 남길지 정리할지 정해두기 |
| 🟡 비중 초과 | 목표보다 +5%p 초과 | 덜어내면 자동으로 비싸게 판 셈 |
| 🔵 채울 자리 | 목표보다 −5%p 미만 | 이번 달 돈은 여기부터 |
| 🟢 그대로 | 목표와 비슷 | 아무것도 하지 않는 게 정답 |

> **손익은 판단 근거가 아니다.** "많이 떨어졌으니 팔아라"도 "많이 올랐으니
> 팔아라"도 둘 다 틀렸다. 그래서 `holdings.js`의 판정 규칙에는 수익률이
> 들어가지 않는다 — 화면에 보여주기만 한다.

## "매일 바뀐다"의 정확한 의미

이 앱은 **주가를 받아오지 않는다.** 그러니 종목 목록이 저절로 매일 바뀌는
기능은 만들지 않았다. 날짜로 종목을 섞어 보여주면 근거 없는 변화를 시장
신호처럼 보이게 만드는 것이라, 투자 앱에서는 그게 가장 나쁜 거짓말이다.

매일 달라지는 건 정확히 둘이다.

1. **사용자가 오늘 맞춘 시장 다이얼** → 국면이 바뀌면 현금 비중, 배분, 그리고
   보유 종목 판정까지 다시 계산된다. 진짜 입력이라 진짜 근거다.
   확인 경과일은 **시장별로 따로** 센다.
2. **오늘의 점검 한 가지** → 날짜에서 나오는 행동 제안. 시장 데이터인 척하지 않는다.

**지수 수치도 같은 이유로 담지 않는다.** 홈의 시장 섹션은 확인 링크(코스피·코스닥·
환율 / S&P500·나스닥·VIX)만 주고, 그 대신 **왜 오르고 왜 내리는지**를 다이얼에서
도출해 ▲/▼ 두 열로 보여준다. 초보자에게는 지수 숫자보다 이쪽이 행동을 바꾼다.

## 핵심 설계: 시황을 적지 않고 판정 규칙을 넣었다

빌드도 서버도 없는 정적 앱에 오늘의 시황을 문장으로 적어 넣으면, 배포한 다음
날부터 틀린 정보가 된다. 정세는 하루 만에 뒤집히는데 파일은 그대로 있는 게
가장 위험하다 — 초보자는 그 낡은 문장을 최신 정보로 믿는다.

그래서 시황을 **적어주는** 대신 **판정 규칙**을 넣었다.

```
사용자가 5개 다이얼을 오늘 값으로 맞춤 (각 30초, 확인 링크 제공)
   금리 방향 · 경기 · 밸류에이션 · 원/달러 환율 · 지정학 긴장도
                        ↓
              market.js 규칙 엔진
                        ↓
   국면 라벨 + 근거 해설 + 배분 조정(%p) + 이번 달 행동
```

파일이 낡아도 결과는 항상 오늘 기준이 되고, 덤으로 사용자가 **무엇을 봐야
하는지**를 배운다 — 이 앱이 사라져도 남는 능력이다.

배분 조정은 **비대칭**이다. 위험을 키우는 방향(+위성)보다 줄이는 방향(+현금)의
절댓값이 크다. 초보자에게는 기회를 놓치는 것보다 크게 다치는 쪽이 훨씬 비싸다.

### 기준일 관리

`market.js`의 `DEFAULTS.asOf`는 **사람이 마지막으로 확인한 날짜**다. 앱이 이
날짜와 오늘을 비교해 며칠 지났는지 화면 최상단에 크게 띄우고, 오래됐으면 경고를
띄운다. 사용자가 다이얼을 한 번이라도 만지면 그 날짜가 `bcc:touched`에 저장되고
이후로는 그 날짜를 기준으로 센다.

```js
var DEFAULTS = {
  asOf: '2026-05-31',        // ← 기본값을 고치면 이 날짜도 반드시 같이 고친다
  kr: { rates: 'hold', growth: 'slow', valuation: 'cheap', fx: 'weak', geo: 'tense' },
  us: { ... }
};
```

## 데이터를 고칠 때 지킬 것

### `data.js`에 넣어도 되는 것 / 안 되는 것

| 넣는다 | 넣지 않는다 |
|---|---|
| 사업 구조, 해자의 성격 | 주가, 시가총액 |
| 배당 정책의 역사 | PER, PBR, 배당수익률 |
| 규제·지정학 노출 | 분기 실적 수치 |
| 확인해야 할 지표의 **이름** | 그 지표의 **현재 값** |

정적 앱에 숫자를 하드코딩하면 그 순간부터 틀린 값이 되고, 초보자는 그걸 믿는다.
대신 각 종목의 `check` 배열로 "직접 확인할 지표"를 주고, 각 시장의 `sources`로
원자료 링크(DART·KRX·한국은행 / SEC EDGAR·FRED·FedWatch)를 준다.

### 점수는 정성 평가다

6축(수요 지속성·해자·재무 체력·현금창출력·주주환원 지속성·지정학 내성)을 0~5로
매긴 **주관적 평가**이며 투자 추천이 아니다. 점수를 올리거나 내릴 때는
근거(`why`)와 리스크(`risk`)를 같이 고칠 것.

평가하는 질문은 **"50년 뒤에 얼마나 오를까"가 아니라 "50년 뒤에도 있을까"** 다.
존속 가능성과 수익률은 다른 질문이고, 이 앱은 전자만 다룬다.

### 종목을 추가할 때

`tag`는 셋 중 하나:

- `core` — 흔들려도 팔지 않을 뼈대
- `income` — 배당 중심
- `satellite` — 변동이 커서 작은 비중으로만 다룰 것

`satellite`로 분류한 종목은 "내 배분"에서 위성 슬롯에만 들어가고 카드에 경고
태그가 붙는다.

## 접근 코드

첫 화면에서 코드를 묻는다. 기본값은 `compass50` — **지인에게 공유하기 전에 반드시
바꿀 것.**

1. 앱을 열고 브라우저 개발자도구 콘솔에서 `BCHash('새코드')` 실행
2. 나온 문자열을 `config.js`의 `hash` 값에 붙여넣기
3. 커밋·푸시 (평문 코드는 파일에 남기지 않는다)

`config.js`에서 `enabled: false`로 두면 코드 없이 열린다.

> ⚠️ **이건 보안이 아니라 문패다.** GitHub Pages는 파일을 그대로 내려주므로
> 소스를 열면 `config.js`도 보인다. "주소를 우연히 알게 된 사람이 그냥 들어오는
> 것"과 "검색에 걸려 흘러드는 것"을 막는 수준이다.
>
> 그래서 **이 앱에는 비밀로 지켜야 할 것을 넣지 않는다.** 계좌번호, 실제 보유
> 종목, 실제 투자 금액을 저장하거나 전송하지 않는다. 입력한 시드조차 브라우저
> 밖으로 나가지 않는다.

### 정말 비공개로 만들려면

| 방법 | 비용 | 실제 차단 |
|---|---|---|
| 지금 방식(코드 + noindex) | 무료 | ✗ 문패 수준 |
| **Cloudflare Pages + Cloudflare Access** | 무료 | ✓ 이메일 인증, 허용 목록 |
| GitHub Pro/Team의 비공개 Pages | 유료 | ✓ |

Cloudflare Access가 가장 현실적이다. 이 저장소를 Cloudflare Pages에 연결하고
Access 정책에 지인 이메일만 넣으면, 링크를 알아도 인증 없이는 파일 자체가
내려가지 않는다.

## 진짜 매일 갱신하려면

지금은 사용자가 다이얼을 맞춰야 국면이 갱신된다. 자동화하려면 서버가 필요하다.

1. **Cloudflare Worker**를 하나 두고 금리·환율·지수 밸류에이션·VIX를 하루 한 번
   가져와 JSON으로 캐시한다(무료 티어로 충분).
2. 앱이 그 JSON을 읽어 다이얼 기본값을 자동으로 채운다.
3. 사용자는 확인만 하고 필요하면 고친다 — **판정 규칙은 그대로 두고 입력만
   자동화하는 것**이 핵심이다. 규칙까지 서버로 옮기면 왜 그런 결론인지
   설명할 수 없게 된다.

API 키는 반드시 Worker 안에만 둔다. 정적 파일에 넣으면 배포 즉시 공개된다.
